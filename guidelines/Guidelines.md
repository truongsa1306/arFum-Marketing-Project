# Tet Campaign Landing Page — Visual Guidelines

## Stance: Luxury Vietnamese Editorial

**Mood:** Tender, intimate, premium. Like a high-end greeting card come to life — warm, slow, emotional. Not festive-loud. Not SaaS-clean.

## Palette

| Token | Value | Use |
|-------|-------|-----|
| Background | `#FAF6F0` | Warm ivory page ground |
| Surface | `#FDF9F4` | Cards, panels |
| Dusty Rose | `#C9968A` | Primary accent, buttons |
| Blush Pink | `#E8C4C0` | Soft fills, section tints |
| Deep Burgundy | `#5C1A24` | Display headings, bold accents |
| Champagne Gold | `#BFA06A` | Gold details, line ornaments |
| Petal Peach | `#F0C8A8` | Blossom highlight |
| Text Dark | `#2D1818` | Body text |
| Text Muted | `#8C7070` | Captions, labels |

## Typography

- **Display:** Playfair Display — used for section headings, emotional statements
- **Script accent:** Dancing Script — sparingly for emotional sub-headings
- **Body:** Lora — readable, warm serif for paragraphs
- Scale: 72/56/40/28/20/16/14px

## Shape Language

- Organic oval frames for photos
- Arch-topped content containers
- Flowing ribbon/silk SVG dividers between sections
- Soft rounded corners (8–16px) on cards
- Gold hairline borders (0.5–1px, 40% opacity)

## Imagery

- Warm-toned, soft-lit Vietnamese family photography
- Peach/apricot blossom overlays (SVG, decorative)
- Subtle champagne-gold geometric ornaments

## Motion

- Fade + translate-up on scroll enter (60ms stagger between siblings)
- Gentle parallax on hero image
- Soft scale hover on cards (1.02×)
- No jarring transitions

## Spacing

Generous vertical rhythm. Section padding: 120px desktop / 72px mobile.
